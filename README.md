The HSSFN adopts a hierarchical network architecture consisting of a spatial encoder, a spectral encoder, and a spectral-spatial decoder. Specifically, the model is designed with a residual spatial encoder to extract spatial features, a multi-scale spectral feature extraction module to capture spectral features at different layers, and a spectral-spatial feature adaptive fusion module in each layer. Additionally, a layer fusion module is incorporated in the spectral-spatial decoder to achieve feature fusion across different layers.
